# BUNKER 404: 건스미스

고물을 주워 총을 만들고, 그 총으로 대피소 문을 지키는 게임.

## 실행

- `index.html` 을 브라우저(크롬 권장)로 열면 바로 됩니다. 설치·빌드 없음.
- 혹은 `python3 dev/server.py` 실행 후 http://localhost:8404

## 조작

| | |
|---|---|
| 마우스 | 조준 · 사격 (꾹 누르면 연사) |
| R | 재장전 / 걸림 해제 |
| 1 · 2 · Q · 휠 | 무기 교체 |
| 우클릭 · Space | 수류탄 (쿨다운 11초) |
| ESC · P | 일시정지 |

## 흐름

1. **낮** — 작업대에서 파츠 9칸을 조합해 총 조립, 원정으로 파밍, 상인과 거래, 시설 건설, 달력으로 다음 습격 확인
2. **밤** — 몰려오는 돌연변이를 막는다. 머리를 쏘면 큰 피해
3. 전리품 상자에서 파츠 1개 선택 → 다음 날

10 · 20 · 30일차는 보스. 30일을 넘기면 무한 모드.

## 조합의 핵심

- **역할 특화** — 파츠마다 장단점이 뚜렷하다. `정예·보스 피해`(🎯 대보스)와 `일반 적 피해`(🐜 대군중)가 서로 반대로 움직이는 파츠가 많아서, 한 자루로 모든 밤을 해결하기 어렵다. 작업대에 두 화력이 따로 표시된다.
- **탄약 경제** — 특수 탄약은 쏠 때마다 화약🧨을 쓴다(몸통 구경에 따라 보정). 한 발이 굵고 비싼 탄은 보스·정예에게, 싸고 넓게 퍼지는 탄은 잡몹 떼에게. 화약이 떨어지면 그 전투 동안 무료 `재생탄`으로 바뀐다. 화약은 원정·상인·시설의 `화약 조제`로 구한다.
- **프리셋** — 작업대에서 조합을 저장해 두고, 달력의 예보(테마·추천)에 맞춰 그날 밤 쓸 총을 한 번에 불러온다.
- **출격 브리핑** — 밤을 맞이하기 전에 오늘 밤의 테마·추천과 내 총 세 자루의 대보스/대군중 화력, 탄약 여유를 한 화면에서 확인한다.
- **악명 🔥** — 흠집 없이(S) 막을수록 소문이 퍼져 다음 무리가 커지고 보상도 늘어난다. 고전하면 가라앉는다.
- **세트 효과** — 같은 계열(고물·배관·군용·주방·사무·하이테크·생체·악기·밈·스포츠·농기구·완구) 3개/5개.
